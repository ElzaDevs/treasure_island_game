# Treasure Island
Um jogo de aventura desenvolvido em **Python**, executado diretamente pelo terminal.
O jogador percorre diferentes situações e precisa tomar decisões para avançar na história e tentar encontrar o tesouro. Cada escolha pode levar a um caminho e resultado diferente.

## Objetivo
Você está em busca de um tesouro escondido em uma ilha misteriosa.
Ao longo da aventura, será necessário tomar decisões para encontrar o caminho até o tesouro. Cada escolha pode levar a uma situação diferente e, em alguns casos, encerrar a jornada.
Seu objetivo é fazer as escolhas certas, chegar à ilha e encontrar o tesouro.

## ASCII Art

O projeto também utiliza **ASCII Art** para criar a identidade visual da aventura diretamente no terminal.
O desenho é formado por caracteres de texto e símbolos, permitindo criar uma representação visual sem depender de imagens ou interfaces gráficas.
Além de tornar a execução mais interessante, essa parte do projeto foi uma oportunidade de trabalhar com **strings multilinha** e a representação de conteúdo textual no terminal.

## Como funciona

A aventura começa em uma encruzilhada. A partir das escolhas realizadas pelo jogador, diferentes situações são apresentadas.
O fluxo inclui:

* Escolha de caminhos;
* Travessia de um lago;
* Chegada a uma ilha;
* Escolha entre três portas;
* Diferentes finais dependendo das decisões.
O objetivo é chegar ao tesouro tomando as decisões corretas.

## Como executar

É necessário ter o **Python 3** instalado.
Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/treasure-island.git
```

Entre na pasta:

```bash
cd treasure-island
```

Execute o programa:

```bash
python treasure-island.py
```
